# Barely Prospecting

A skyblock progression mod for Forge and NeoForge. You start on a tiny island in the void and refine everything by hand: break rubble, pan silt, crush grit and pan it again, soak, fire and fuse. Every step is a manual action on a block, and each result feeds the next step.

See `SPEC.md` for the design. Status is in `PROJECT_STATUS.md`.
